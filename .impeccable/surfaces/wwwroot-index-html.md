# App panel (wwwroot/index.html)

Scope: the single-window Photino app, 6 screens (Candidatar, Avisos, Histórico, Respostas salvas, Perfil, Perguntar; Ctrl+1…6). Copy is plain pt-BR; the postal world lives in the visuals, not the words. Mode: Operate. UI language: pt-BR.
Audience: one dev who starts a run, leaves, comes back. Task on return: see what happened, clear what depends on them.
Rule decided: uncertain question → discard the application, job becomes "aguardando você", aviso created, run goes on; once answered, the job returns to the queue on the next dispatch.

## Direction contract

THESIS: each application is a registered object (code, event trail, receipt). Refuses the default dark sidebar + KPI cards + table.
OWN-WORLD: ruled form paper #F4F1E8, ink #1C2B4A, registration red #C8102E only for what waits on you, kraft #B98B52 for secondary layers, delivered green #2F7D4F. Segoe UI Variable + Cascadia Mono for codes/counts. Rubber-stamp statuses (bordered caps, slight rotation), registered-label code chips, diagonal stripe = disabled.
STORY: on return, the user sees how many avisos wait, answers them in place, trusts the ledger.

Left, the dominant aviso stack with its count at the largest size on screen. Right, the franking counter (fixed digits) over the trail of the object in transit + tracking log.
